# Maintaining the profile

Update the English and Chinese READMEs together. Keep the project grid and thumbnails in the same order as [featured.json](featured.json).

Use the [portfolio directory](https://github.com/Daniel-24-life/portfolio) for the complete project list. Refresh the profile counts from public repositories, verified project test results, and reachable live demos.

Run the profile verification with `python scripts/verify_profile.py`.
